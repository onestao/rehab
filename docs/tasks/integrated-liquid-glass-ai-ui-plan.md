# 一体化液态玻璃 AI 界面修改计划

> 日期：2026-07-11  
> 状态：待用户确认  
> 目标分支：`perfrom`，完成后同步 `ui-mockup`  
> 设计结论：采用“一体化液态玻璃”，模型入口仅显示图标与叠放式下拉箭头

## 1. 修改目标

1. 重构 AI 教练底部输入区、移动端底部导航和模型/推理选择抽屉，使其形成统一的液态玻璃视觉系统。
2. 输入栏最大限度保留输入空间，模型入口不再常驻模型名称。
3. 完整复用现有模型图标库及其 CDN、本地 SVG、文字标记三级回退能力。
4. 保持现有任务级模型与推理强度持久化、收藏、最近使用、备用模型授权和报告版本功能不变。
5. 不增加后端、bundler 或新的第三方 UI 依赖，不提高现有 size-limit 上限。

## 2. 已确认交互

### 2.1 输入栏

移动端目标结构：

```text
[模型图标⌄] [推理图标] [        输入内容        ] [发送]
```

- 模型入口总占位约 `36 x 36px`。
- 模型图标约 `24–26px`；下拉箭头作为右下角角标叠放，不单独占一列。
- 输入栏内不显示模型名称，也不显示用于恢复默认的 `×`。
- 推理强度保留 B3 磨砂冰晶闪电，按钮约 `30–32px`。
- 发送按钮约 `38–40px`；无内容时进入低强调玻璃状态。
- 文本输入区域使用 `flex: 1` 和 `min-width: 0`，作为唯一可伸缩区域。

### 2.2 模型名称的显示位置

- 点击模型入口后，在模型抽屉标题区显示完整模型名、连接名和图标。
- 模型切换成功后显示短暂 toast，例如“已切换至 GPT-5.5”。
- 已生成答案的版本/元数据栏显示对应模型短名，用于比较不同模型的答案。
- 输入栏不增加悬浮常驻标签；避免遮挡内容、形成第二视觉焦点。
- `GPT-5-5` 与 `GPT-5.5` 始终保持为两个不同模型。

### 2.3 模型与推理抽屉

- 继续复用唯一的 `#aiModelPickerSheet`，不新增第二套 modal。
- 模型抽屉顺序维持“收藏 → 当前功能最近使用 → 按连接分组”。
- 模型条目显示模型图标、完整模型名、连接副标题、收藏和选中状态。
- 推理菜单点击选项后立即保存并关闭。
- 完整设置仍负责备用模型、自动回退授权和恢复默认。

### 2.4 底部导航

- 移动端五项导航统一改为半透明玻璃底座；桌面导航轨保持现有结构。
- 当前项使用轻量玻璃透镜，不使用大面积实色胶囊。
- AI 页面中输入栏和导航栏在视觉上连接为上下两层；其他页面只显示导航层。
- 不把输入框移动到全局导航 DOM 中，避免破坏页面生命周期、草稿保存和虚拟键盘行为。

## 3. 模型图标库兼容方案

现有图标能力位于 `advice-render.js`：

- `MODEL_ICON_SLUGS`：Lobe 图标名称映射。
- `MODEL_ICONS`：`assets/model-icons/*.svg` 本地资源。
- `iconFallbackSrcs()`：彩色 CDN → 单色 CDN → 本地 SVG → `generic.svg`。
- `adviceModelVisual()`：根据 `model / provider / iconKey` 解析品牌视觉。

本次不会复制这套映射。计划抽出一个共享的轻量模型视觉解析模块：

```js
window.aiModelVisual.resolve({ modelId, provider, iconKey })
// -> { key, label, mark, iconSrcs, theme }
```

使用规则：

1. `advice-render.js` 改为调用共享 resolver，并删除迁出的常量和重复识别正则。
2. `ai-task-settings.js` 删除当前首字母色块 `connectionMark()`，改用同一 resolver。
3. 输入栏、模型抽屉、设置页和答案元数据使用同一个品牌判定结果。
4. 图标保持原始颜色，不施加统一 `filter`、`mask` 或强制单色。
5. 远程图标不可用或离线时继续回退本地 SVG；未知模型回退 `generic.svg` 和安全文字标记。
6. 图标容器负责玻璃背景，图标本身不参与玻璃透明度，避免品牌图形发灰。

## 4. 两个内部实施阶段

## 阶段一：共享模型视觉与紧凑控件

### 目标

- 先解决输入空间、图标复用和控件一致性。
- 不改变聊天内容布局和底部导航，降低第一阶段回归范围。

### 代码修改

| 文件 | 修改内容 |
|---|---|
| `ai-model-visual.js` | 新增共享 resolver；从 AI 教练迁移图标映射、回退顺序和品牌识别 |
| `advice-render.js` | 调用共享 resolver，删除已迁出的重复代码，保留 AI 教练渲染适配 |
| `ai-task-settings.js` | 模型按钮改为图标加角标箭头；模型列表接入共享图标；删除 `connectionMark()` |
| `advice-panel.js` | 移除模型按钮中的 `×`；切换后显示 toast；完整名称留在抽屉与答案元数据 |
| `css-src/54-v6-ai.css` | 新增共享模型图标槽、紧凑模型按钮、推理按钮和输入栏尺寸规则 |
| `css-src/20-settings-ai.css` | 设置页只保留宿主布局，迁出重复控件外观 |
| `css-src/48-advice-model-picker.css` | 保留 AI 教练特有定位，删除与共享模型行重复的规则 |
| `index.html`、`sw.js` | 添加共享脚本加载顺序和离线预缓存，更新版本号 |

### 阶段一验收

- `430 x 932` 下模型入口不超过约 `36px`，输入框获得主要剩余宽度。
- OpenAI、Claude、Gemini、DeepSeek、Qwen、Kimi 等现有图标正常显示。
- CDN 失败和离线状态能回退本地图标。
- 未知模型有稳定 fallback，不出现破图。
- 模型选择、收藏、最近使用和功能级持久化行为保持不变。
- 模型切换不触发生成，只显示确认 toast。

## 阶段二：一体化液态玻璃底座与抽屉

### 目标

- 完成 AI 教练输入区、模型/推理抽屉和移动端底部导航的统一视觉升级。
- 保持 M3E 的触控反馈、动效节奏和无障碍行为。

### 代码修改

| 文件 | 修改内容 |
|---|---|
| `css-src/54-v6-ai.css` | AI 输入栏玻璃表面、边缘高光、内阴影、聚焦态和发送态 |
| `css-src/46-advice-ai.css` | AI 教练页面留白、消息区底部避让、composer 宿主布局 |
| `css-src/27-layout-nav.css` | 移动端导航玻璃底座与当前项透镜；桌面轨道不改 |
| `css-src/20-settings-ai.css` | 快速模型/推理抽屉的紧凑行高与移动端安全区 |
| `css-src/37-dark-mode.css` | 仅放暗色模式所需的玻璃 token 覆盖 |
| `index.html` | 在 `_activateTab()` 同步稳定的活动页面 dataset，供 AI 页面组合态使用 |
| `advice-panel.js` | 保持现有 composer DOM 与草稿逻辑，只增加必要状态类和元数据挂点 |

### 视觉规则

- 玻璃效果由半透明表面、背景模糊、`1px` 边缘高光和轻阴影组成。
- 不使用大面积彩色渐变；品牌色只出现在模型图标、推理状态和发送动作。
- AI 页面 composer 与 nav 使用相同左右边距、边框和模糊参数，视觉连续但 DOM 解耦。
- 所有动画只使用 `transform / opacity`，并遵守 `prefers-reduced-motion`。
- `backdrop-filter` 不支持时退化为不透明 surface token，不影响可读性。

### 阶段二验收

- 浅色与暗色主题均保持清晰边界和文字对比度。
- `430 x 932`、`390 x 844`、`360 x 800` 均无横向溢出或控件重叠。
- 虚拟键盘弹出后输入栏、发送按钮和文本光标仍可见。
- 底部安全区正确，导航触控目标不少于 `44 x 44px`。
- 模型抽屉支持遮罩、关闭按钮、系统返回和已有下滑关闭机制。
- 其他四个主页面的底部导航正常，页面内容不被遮挡。
